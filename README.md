# Магазин обуви

Учебный проект по разработке информационной системы для автоматизации работы магазина обуви.

## Команда проекта
* **KotMir**
* **TimeShift **

## Технологический стек
* **Язык программирования:** C#
* **Платформа / Фреймворк:** .NET (WPF / Windows Forms)
* **База данных:** MS SQL Server / SQLite
* **Система контроля версий:** Git (GitHub)

## Структура репозитория
* `docs/` — документация проекта (паспорт, Диаграмма Гантта, отчёты)
* `db/` — скрипты создания и наполнения базы данных, схемы
* `src/` — исходный код приложения
